# Spikes

Long-form notes that would push a backlog entry past its 45-line cap: design notes, research,
evidence tables, lessons from a failed attempt. Name each file after the entry it supports,
`<id>_<short_slug>.md` (e.g. `T2.7_cache_invalidation.md`), and link it from that entry's
**Background** line.

When the entry moves to `COMPLETED.md`, the spike stays here as the record of how the decision
was reached. Keep the filename, because the completed entry links to it.
